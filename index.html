Closures / hookfunction

hookfunction

Redirects all calls to a target function through a hook, returning the original so you can still invoke it.

Warning: Upvalue limit
The hook function must not carry more upvalues than the function being hooked. To work around this, wrap the hook in newcclosure or newlclosure first. All closure type pairings (L→L, L→NC, NC→C, etc.) are expected to be supported.
function hookfunction<A1..., R1..., A2..., R2...>(target: (A1...) -> R1..., hook: (A2...) -> R2...): (A1...) -> R1...

Parameters

ParameterDescription
targetThe function whose call path will be intercepted.
hookThe replacement function that runs in its place.

Returns

The original, unhooked function - call this inside your hook to preserve the original behavior.

Example

LUAUBasic hook and restore
local function greet()
    print("hey from original")
end

local orig = hookfunction(greet, function()
    print("intercepted")
end)

greet()   -- Output: intercepted
orig()    -- Output: hey from original
LUAUWrapping around print to log arguments
local real_print = hookfunction(print, newcclosure(function(...)
    -- log to our own system first
    real_print("[salad log]", ...)
end))
Closures / newcclosure

newcclosure

Wraps a Luau function inside a C closure so it appears native to the engine's type checks.

ℹ Use with hookfunction
Wrapping hooks with newcclosure lets you bypass the upvalue count restriction imposed by hookfunction.
function newcclosure<A..., R...>(fn: (A...) -> R...): (A...) -> R...

Parameters

ParameterDescription
fnThe Luau function to wrap as a C closure.

Example

LUAUType verification after wrapping
local function my_func() end
print(iscclosure(my_func))              -- false

local wrapped = newcclosure(my_func)
print(iscclosure(wrapped))             -- true

Debug / getconstants

debug.getconstants

Returns a table of every constant embedded in a Luau function's compiled bytecode - strings, numbers, booleans, and nil.

⚠ Luau only
Passing a C closure will raise an error.
function debug.getconstants(fn: ((...any) -> (...any)) | number): { number | string | boolean | nil }

Parameters

ParameterDescription
fnA Luau function or a stack level number (1 = current function).

Example

LUAUDumping constants from a closure
local function target()
    local msg = "hello salad"
    string.format(msg, "world")
end

for i, v in debug.getconstants(target) do
    print(i, v)
end
-- 1  "string"
-- 2  "format"
-- 4  "hello salad"
-- 5  "world"

Debug / setstack

debug.setstack

Writes a value into a specific slot of a running stack frame. Powerful for patching locals and arguments mid-execution.

⚠ C stack frames unsupported
Targeting a stack level that points at a C closure will throw.
function debug.setstack(level: number, index: number, value: any): ()

Parameters

ParameterDescription
levelStack depth. 1 = current function, 2 = its caller, etc.
indexSlot index within that frame to overwrite.
valueThe value to place at that slot.

Example

LUAUSwapping a parent-scope local at runtime
local score = 0

local function bump()
    score += 1
    debug.setstack(2, 1, 1000)
end

bump()
print(score)  -- 1000

Instances / fireclickdetector

fireclickdetector

Triggers a ClickDetector event remotely, bypassing distance and interaction requirements. Should not be implemented in Luau as it creates easy detection vectors.

Warning: Avoid Luau implementation
This function should not be implemented in Luau. Doing so exposes you to easy detection vectors.
function fireclickdetector(detector: ClickDetector, distance?: number, event?: string): ()

Parameters

ParameterDescription
detectorThe ClickDetector instance to trigger.
distance?Simulated distance from which the click originates. Defaults to infinite (no limit).
event?Which event to fire — e.g. MouseClick, RightMouseClick, MouseHoverEnter, MouseHoverLeave. Defaults to MouseClick.

Example

LUAUFiring different ClickDetector events
local cd = Instance.new("ClickDetector")

cd.MouseClick:Connect(function(player) print(player.Name, "M1") end)
cd.RightMouseClick:Connect(function(player) print(player.Name, "M2") end)
cd.MouseHoverEnter:Connect(function(player) print(player.Name, "HoverEnter") end)

fireclickdetector(cd, 0, "MouseClick")
fireclickdetector(cd, 0, "RightMouseClick")
fireclickdetector(cd, 0, "MouseHoverEnter")

Home / WebSocket

WebSocket

Bi-directional persistent socket connections from within Roblox scripts.

⚠ Client only
WebSocket is a client implementation - you cannot host a server through it. Use wss:// (secure) endpoints wherever possible.

Constructor

function WebSocket.connect(url: string): WebSocket

Attempts to open a WebSocket connection to the provided URL. The URL must start with ws:// or wss://.

Events

EventDescription
OnMessage(msg: string)Fires each time a message is received over the connection.
OnClose()Fires when the connection closes for any reason.

Methods

MethodDescription
:Send(msg: string)Transmits a string message over the open connection.
:Close()Closes the connection and triggers OnClose.

Examples

LUAUEcho server round-trip
local ws = WebSocket.connect("wss://ws.postman-echo.com/raw")

ws.OnMessage:Connect(function(msg)
    print("received:", msg)
end)

ws:Send("ping")  -- Output: received: ping
LUAUGraceful close with callback
local ws = WebSocket.connect("wss://ws.postman-echo.com/raw")
ws.OnClose:Connect(function()
    print("connection closed")
end)
ws:Close()  -- Output: connection closed
